# Contributing to Aditya E-Commerce

## Development Guidelines

- Keep frontend and backend changes organized in their respective directories.
- Follow the existing project structure and naming conventions.
- Keep changes focused and avoid committing generated build files or secrets.

## Backend Setup

1. Install Java 21 or later and configure the MySQL database.
2. Open the backend directory.
3. Start the application using:

```bash
./mvnw spring-boot:run
```

## Running Tests

Run backend tests from the backend directory:

```bash
./mvnw clean test
```

## Commit Guidelines

- Use clear, descriptive commit messages.
- Keep each commit focused on one logical change.
- Review your changes before pushing.
